# Auto-push to GitHub

After completing code changes in this repo (`shadow-depths`), automatically:

1. Run `git status` — if there are no changes, skip.
2. Stage all relevant changed files (never commit secrets like `.env`).
3. Commit with a clear message describing the fix/feature.
4. Push to `origin main` without asking the user for confirmation.

Do not ask "mau push?" — the user requested automatic push (May 2026).
