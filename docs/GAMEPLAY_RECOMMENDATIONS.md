# Shadow Depths Gameplay Recommendations

Roadmap gameplay untuk menaikkan kualitas run 100 floor sebelum Play Store.

1. Buat struktur 100 floor punya milestone kuat: setiap 10 floor harus terasa seperti chapter dengan biome, musuh, mechanic, boss atau vault, dan reward besar.
2. Tambahkan biome mechanic unik: Frozen Halls bisa punya slow tile, Magma Foundry punya lava pressure, Mirror Vaults punya clone atau reflection.
3. Perkuat boss tiap 10 floor: boss perlu pattern, telegraph, phase change, dan arena hazard, bukan hanya stat besar.
4. Jadikan subboss tiap 5 floor sebagai skill check yang menguji mechanic biome sebelum boss besar.
5. Buat difficulty curve lebih terbaca dengan playtest data seperti average HP lost, death floor, dan kill time.
6. Tambahkan enemy intent icon agar pemain tahu serangan melee, ranged, charge, buff, flee, atau summon sebelum turn musuh.
7. Perbanyak enemy role, bukan hanya enemy stat: blocker, sniper, charger, healer, trapper, splitter, disabler, exploder.
8. Elite affix harus punya counterplay jelas, misalnya Shielded lemah magic, Swift lemah slow/freeze, Vampiric harus diberi warning.
9. Loot harus mendukung build archetype seperti bleed, lifesteal, crit, ranged, spell, tank, torch/scout, poison, dan freeze.
10. Skill synergy perlu UI eksplisit agar pemain paham threshold Fury, Ward, Hunt, dan Arcane saat memilih skill.
11. Tambahkan reroll atau banish skill agar run panjang tidak rusak oleh pilihan level-up yang buruk.
12. Forge harus jadi strategic checkpoint untuk upgrade item utama, reroll affix, socket rune, atau convert material.
13. Vault harus punya risk-reward, misalnya chest aman kecil atau cursed chest besar yang memanggil ambush/elite.
14. Tambahkan pressure jangka panjang ringan seperti corruption, wound, torch decay, atau fatigue tanpa membuat run terasa menghukum.
15. Buat potion dan consumable lebih taktis: blink, smoke, cleanse, reveal, trap disarm, temporary armor, atau boss interrupt.
16. Perkuat ranged focus sebagai resource dengan item/skill untuk reload on kill, overcharge, regen on wait, atau heavy shot.
17. Hero identity harus bertahan sampai late game lewat hero-exclusive skill chain atau legendary relic khusus hero.
18. Tambahkan decision di stairs: descend normal, cursed shortcut, spend gold to scout, atau sacrifice HP for bonus loot.
19. Perkuat death recap dengan penyebab mati, floor, build, item terbaik, dan hint kesalahan.
20. Tambahkan daily seed dan run modifier untuk retention: fixed seed, fixed hero bonus, special rule, dan score lokal.

Priority:

- P0: enemy intent, boss pattern, biome mechanic, skill synergy UI, death recap.
- P1: forge/vault risk-reward, hero-exclusive progression, richer consumables, clearer difficulty curve.
- P2: daily seed, run modifiers, leaderboard, advanced late-game build systems.
